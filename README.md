# 23CSE301 Machine Learning Capstone Project (Review 1)

## Project Overview
This repository contains end-to-end Machine Learning pipelines developed for the 23CSE301 Capstone project covering the Full Regression Track and Classification Track Part A.

## Datasets
* **Regression:** House Sales in King County, USA (`kc_house_data.csv`) to predict residential property prices.
* **Classification:** Bank Marketing Data Set (`bank-full.csv`) to predict term-deposit subscription outcomes.

## Algorithms Implemented

### Regression Track (10 Algorithms)
1. Linear Regression (Baseline)
2. Ridge Regression (L2 Regularization)
3. Lasso Regression (L1 Regularization)
4. ElasticNet Regression (L1 + L2 Regularization)
5. Polynomial Regression (Degree 2)
6. Decision Tree Regressor
7. Random Forest Regressor
8. Gradient Boosting Regressor (GBM)
9. Support Vector Regressor (SVR)
10. K-Nearest Neighbors Regressor (KNN)

### Classification Track — Part A (5 Algorithms)
1. Logistic Regression (Baseline)
2. K-Nearest Neighbors Classifier (KNN)
3. Naive Bayes (Gaussian)
4. Decision Tree Classifier
5. Support Vector Machine (SVC)
